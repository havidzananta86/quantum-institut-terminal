Broker MT5 & Eksekusi

Sambungkan akun MetaTrader (read-only), atur batas risiko eksekusi real, dan lihat apakah EA Anda hidup. Mode "Real MT5" di Quick Trade memakai pengaturan ini.

Hubungkan MetaTrader secara read-only

Bridge ini hanya menerima ringkasan akun. Jangan pernah masukkan password broker, investor password, atau API key broker.

Endpoint untuk EA — salin apa adanya
Memuat endpoint…

Di MetaTrader buka Tools → Options → Expert Advisors, centang Allow WebRequest for listed URL, lalu tambahkan …. Tanpa langkah ini EA tidak bisa mengirim snapshot sama sekali (log EA menampilkan HTTP=-1).

Akun terdaftar di bridge

Kalau ada akun yang salah platform (misalnya MT4 padahal terminal Anda MT5), klik Cabut pada baris itu supaya tidak ikut menunggu.

Simpan Bridge Key ini sekarang. Demi keamanan, key tidak dapat ditampilkan lagi.
  1. Unduh EA MT4 atau EA MT5 — input Endpoint di dalamnya sudah terisi otomatis untuk domain ini (versi manual: template MT5).
  2. Buka file itu di MetaEditor, compile, lalu pasang EA ke satu grafik di terminal yang memakai akun ini.
  3. Centang Allow WebRequest for listed URL dan tambahkan ….
  4. Isi input BridgeKey pada EA dengan key di atas, lalu aktifkan AutoTrading — hanya supaya timer EA berjalan, EA tidak mengirim order.
  5. Status pada kartu Akun Trading berubah menjadi TERHUBUNG otomatis setelah snapshot pertama diterima (maksimal 60 detik).

Cara mendapatkan token & chat id
  1. Buka Telegram → cari @BotFather → kirim /newbot → ikuti petunjuk.
  2. BotFather memberi token berbentuk 123456789:AA… → tempel di kolom Token.
  3. Kirim pesan apa pun ke bot Anda, lalu buka https://api.telegram.org/bot<token>/getUpdates dan ambil nilai chat.id.
  4. Untuk kanal: tambahkan bot sebagai admin kanal, lalu pakai @namakanal.
  5. Tekan Simpan & Kirim Uji — pesan uji harus masuk ke Telegram Anda.
Eksekusi MT5 akun real — nonaktif secara default

Buat dan aktifkan hanya setelah EA MT5 terhubung. Limit ini adalah batas keras server: 0,01 lot, rugi harian maksimal 50%, dan 10 posisi.

Memuat status eksekusi MT5…
Unduh EA Eksekusi MT5 (Endpoint terisi otomatis)

Nama simbol berbeda antar broker (XAUUSD vs XAUUSD.pro vs GOLD). Tanpa pemetaan, EA menolak dengan “Symbol is unavailable”. Tulis XAUUSD= (nilai kosong) bila simbol itu tidak ingin dieksekusi di akun ini. Huruf besar/kecil nilai dipertahankan.

Lot tetap 0,01 (batas keras server & EA).
Tekan “Muat status eksekusi” untuk melihat kesegaran EA dan perintah terakhir.
Panduan memasang EA EKSEKUSI (5 langkah)
  1. Akun ini harus berpaket PRO/VIP, dan guardrail sudah disimpan (minimal satu simbol diizinkan).
  2. Unduh EA Eksekusi MT5 di tautan di atas → buka di MetaEditor → Compile.
  3. Di MT5: Tools → Options → Expert Advisors → centang Allow WebRequest for listed URL → tambahkan https://quantum-institut.com.
  4. Pasang EA ke satu grafik, isi input BridgeKey akun ini, biarkan AllowRealExecution=false lebih dulu, lalu nyalakan tombol AutoTrading. Status di atas harus berubah menjadi “EA hidup”.
  5. Setelah yakin, ubah AllowRealExecution=true lalu tekan Aktifkan Real. MT5 harus tetap berjalan — PC sendiri atau VPS Windows.

Perintah hanya dikirim bila semua terpenuhi: akun PRO/VIP, eksekusi aktif, terminal tersambung, simbol diizinkan, lot ≤ 0,01, rugi harian di bawah batas, dan posisi belum penuh. Satu sinyal = satu perintah per akun. EA memeriksa ulang semuanya secara lokal sebelum mengirim order, dan melaporkan tiket + kode hasil kembali ke sini.
