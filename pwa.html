Cara Install Aplikasi

Quantum Institut Market Terminal dapat diinstall sebagai Progressive Web App (PWA) di perangkat Anda — tampilan seperti aplikasi native, tanpa perlu Google Play atau App Store.

⚡
Cepat
Cache lokal, akses instan
📴
Offline
Tetap buka tanpa internet
🏠
Home Screen
Icon di layar utama
🔔
Notifikasi
Push alert sinyal AI

Browser yang didukung: Chrome, Edge, Samsung Internet, Brave

1
Buka di Chrome Android

Akses quantum-institut.com menggunakan Google Chrome di HP Android Anda.

2
Ketuk tombol menu (⋮)

Tap ikon tiga titik vertikal ⋮ di pojok kanan atas browser Chrome.

3
Pilih "Add to Home Screen"

Pilih opsi "Tambahkan ke layar utama" atau "Add to Home Screen" dari menu dropdown.

4
Konfirmasi nama aplikasi

Sebuah popup akan muncul menampilkan nama "Quantum Institut". Ketuk Add / Tambah untuk mengkonfirmasi.

5
Selesai! Icon muncul di Home Screen

Ikon Quantum Institut akan muncul di layar utama HP Anda. Ketuk untuk membuka seperti aplikasi biasa — tanpa address bar browser.

💡 Beberapa Android menampilkan banner instalasi otomatis di bagian bawah browser jika Anda sering mengunjungi situs ini. Ketuk banner tersebut untuk proses yang lebih cepat.

Browser yang didukung: Safari (wajib — Chrome iOS tidak mendukung PWA install)

1
Buka Safari

Akses quantum-institut.com menggunakan Safari di iPhone atau iPad Anda. Chrome iOS tidak bisa install PWA.

2
Ketuk ikon Share (□↑)

Tap ikon Share (kotak dengan panah ke atas □↑) yang ada di toolbar bawah Safari.

3
Scroll dan pilih "Add to Home Screen"

Dari menu Share yang muncul, scroll ke bawah dan ketuk "Add to Home Screen" atau "Tambah ke Layar Utama".

4
Beri nama dan ketuk "Add"

Edit nama jika diinginkan, lalu ketuk Add di pojok kanan atas. Ikon akan ditambahkan ke Home Screen Anda.

⚠ iOS 16.4+ diperlukan untuk push notifications. Jika menggunakan iOS lebih lama, fitur dasar PWA tetap berjalan tetapi notifikasi tidak tersedia.

Browser yang didukung: Chrome, Edge (Chromium). Firefox tidak mendukung install PWA di desktop.

1
Buka di Chrome atau Edge

Akses quantum-institut.com di browser Chrome atau Microsoft Edge di komputer Anda.

2
Cari ikon install di address bar

Perhatikan address bar — ada ikon ⊕ (install) atau ikon komputer kecil di sisi kanan. Klik ikon tersebut.

3
Klik "Install"

Sebuah dialog akan muncul. Klik tombol Install untuk mengkonfirmasi. Aplikasi akan dibuat shortcut-nya di Desktop dan Start Menu.

4
Buka dari Desktop / Start Menu

Setelah install, Quantum Institut akan muncul sebagai aplikasi terpisah di taskbar. Jalankan seperti aplikasi biasa — tanpa Chrome/Edge UI yang mengganggu.

Cara alternatif (Chrome menu):
1. Klik menu ⋮ di pojok kanan atas Chrome
2. Pilih Save and share → Create shortcut...
3. Centang "Open as window" lalu klik Create

Pertanyaan Umum

Apakah ini aman? Apakah ada akses ke kamera/mikrofon? ▼
PWA hanya meminta izin yang Anda setujui secara eksplisit. Quantum Institut tidak meminta akses kamera, mikrofon, atau kontak. Hanya izin notifikasi (opsional) yang mungkin diminta untuk push alert sinyal AI.
Apakah data saya tersimpan offline? ▼
Ya. Data pengaturan, histori sinyal, dan posisi paper trading tersimpan di localStorage perangkat Anda. Data harga real-time memerlukan koneksi internet.
Cara uninstall / hapus aplikasi? ▼
Android: Tekan lama ikon → Hapus dari layar utama / Uninstall.
iOS: Tekan lama ikon → Remove App → Remove from Home Screen.
PC: Buka aplikasi → klik ⋮ di pojok kanan atas → Uninstall.
Apakah data login saya terbawa saat pindah perangkat? ▼
Login akan terputus jika Anda menggunakan perangkat berbeda — Anda perlu login ulang. Ini adalah fitur keamanan standar. Cukup masuk dengan email dan password Anda di perangkat baru.
