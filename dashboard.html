SL dan TP posisi manual ditegakkan server di feed eksekusinya, juga saat dashboard tertutup. R = jarak SL awal ke entry. Break-even memindah SL ke entry saat profit mencapai nilai itu; trailing mulai di titik yang sama lalu mengikuti harga sejauh nilai R-nya. Keduanya dihitung di dashboard selama terbuka dan baru berlaku setelah server menerimanya, hanya untuk posisi manual; posisi AUTO/AI dikelola server.
